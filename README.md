# FQ4 — Triagem de Atendimento

Página para direcionar clientes da FQ4 de acordo com:

* Estado
* Cidade
* Consumo mensal de combustível

## Estrutura atual

* `index.html` — página principal
* `script.js` — lógica de seleção de estado e cidade

## Funcionamento

O cliente seleciona o estado e, em seguida, o sistema carrega automaticamente as cidades daquele estado através da API de municípios do IBGE.
